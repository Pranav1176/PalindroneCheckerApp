# PalindromeCheckerApp
A simple Java application that checks whether a given string or number is a palindrome.
Overview
PalindromeCheckerApp is a beginner-friendly console-based program designed to demonstrate basic programming concepts such as string manipulation, loops, and conditional logic.
A palindrome is a word, phrase, or number that reads the same forward and backward.

Examples:
madam → Palindrome

121 → Palindrome

hello → Not a Palindrome

Objective
The purpose of this project is to:
Understand string handling in Java
Practice loop implementation
Apply conditional statements
Build basic algorithmic thinking
This project focuses on logic clarity rather than complexity.
